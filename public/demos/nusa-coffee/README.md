# Nusa Coffee

Template landing page mandiri untuk bisnis kafe atau coffee shop.

## Struktur

- `index.html` — konten dan struktur halaman
- `styles.css` — seluruh tampilan responsif
- `script.js` — interaksi menu mobile

Folder ini tidak bergantung pada aplikasi katalog MOVETRA. Untuk proyek klien,
salin seluruh folder, ubah nama brand, teks, warna, tautan WhatsApp, dan domain.
